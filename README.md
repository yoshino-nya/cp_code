# cp_code

这是存算法题代码的仓库，主要是 Codeforces 和 Luogu 的题目。

- codeforces 按比赛编号为文件夹名字，例如 `codeforces/2277` 对应 `https://codeforces.com/contest/2277`，每题单独文件。
  
- luogu 每个题目一个文件夹，`luogu/P1006` 对应洛谷 `P1006` 题。

其他目录目前有点乱，等待整理……

> 最开始不会用 git，然后也觉得存这种代码没什么意义，毕竟写算法题 IDE 永远只需要开一个文件☝️🤓。之后发现每题独立文件看起来挺舒服的，以及把写的每一题的代码存下来挺有意思，可以看着自己的 commits 和文件夹越来越多。
